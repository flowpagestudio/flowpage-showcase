# FlowPage Studio — Design System

## עיקרון
כל דף חדש משתמש באותה תשתית. מותר לשנות תוכן, תמונות וצבע משני; אין לשנות את השלד, הניווט או היררכיית הרכיבים.

## צבעים
- רקע: `#FCFAF5`
- כהה: `#23211E`
- טורקיז: `#1F6F63`
- Computer: `#3D7EA6`
- Pedicure: `#B97878`
- Baking: `#C88745`

## טיפוגרפיה
עברית: Assistant. אנגלית ומספרים: Space Grotesk.

## שלד דף פרויקט
Header → ניווט פרויקטים → Hero → תיאור → צורך → פתרון → תהליך → יכולות → גלריה/המחשה → דמו → CTA → Footer.

## הוספת פרויקט בעתיד
1. להוסיף קישור לניווט.
2. לבחור צבע משני ואייקון.
3. להשתמש ב־`flowpage-theme.css` וב־`flowpage-components.css`.
4. להוסיף את `data-flowpage-project`.
5. לשמור על אותם גדלי כרטיסים, כפתורים, מרווחים ויחסי תמונה.
6. לבדוק מובייל, מחשב, קישורים ונגישות.
