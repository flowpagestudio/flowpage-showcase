# פדיקור ומניקור — חבילת העתקה ל־Google Apps Script

יש לבצע את כל הפעולות רק בחשבון `flowpagestudio@gmail.com`.

## קבצים להדבקה

| קובץ במאגר | שם קובץ ב־Apps Script |
|---|---|
| `Code.gs` | `Code.gs` |
| `Index.html` | `Index` |
| `Management.html` | `Management` |
| `appsscript.json` | Project Settings → Show `appsscript.json` |

## הקמה ראשונית

1. צרו פרויקט Apps Script חדש בחשבון העסקי והדביקו את ארבעת הקבצים.
2. שמרו והריצו פעם אחת את `setupProject`. הפעולה יוצרת אוטומטית גיליון תורים ותיקיית גלריה ייעודיים.
3. בעורך, הריצו פעם אחת `setAdminPin('קוד-חזק-של-לפחות-8-תווים')`. הקוד אינו נכנס לגיליון ואינו מופיע באתר.
4. פרסמו Web App: **Execute as: Me**, **Who has access: Anyone**.
5. כתובות המערכת:
   - קביעת תור: `/exec`
   - ניהול בעלת העסק: `/exec?view=management`
   - גלריה ציבורית: `/exec?view=gallery`

## מה המנהלת יכולה לעשות

- לראות את כל התורים ולסמן אותם כהושלמו, בוטלו או לא־הגיעה.
- ביטול מוחק את האירוע מהיומן ומעדכן את הלקוחה אם הוזן מייל.
- להחליף תמונות, כותרות וקטגוריות בגלריה מהטלפון.
- לקבוע את כתובת מייל ההתראות ואת היומן הפעיל.

## בדיקת מסירה

1. קבעו תור בדיקה מהכתובת הציבורית.
2. ודאו שהאירוע נכנס ליומן ושנוצרה שורה בגיליון `תורים`.
3. היכנסו ל־`?view=management` עם קוד הניהול ושנו סטטוס.
4. החליפו תמונת גלריה ובדקו את `?view=gallery`.
