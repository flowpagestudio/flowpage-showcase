# התקנת BakeFlow ב-Google Apps Script

## לפני שמתחילים

הפרויקט מיועד לחשבון העסקי בלבד: `flowpagestudio@gmail.com`.

1. פתח Google Sheet חדש בשם `BakeFlow - ניהול ייצור`.
2. מתוך הגיליון בחר **הרחבות > Apps Script**.
3. צור שני קבצים והעתק אליהם את התוכן מהמאגר:
   - `Code.gs`
   - `Management.html`
4. החלף את תוכן `appsscript.json` בתוכן קובץ ההגדרות מהמאגר.
5. שמור את הפרויקט.

## הקמה ראשונית

1. בעורך Apps Script בחר בפונקציה `setupBakeFlow`.
2. לחץ **הפעלה** ואשר את ההרשאות לחשבון העסקי.
3. חזור לגיליון. יווצרו בו כל הגיליונות, קטלוג הדגמה ומתכונים.
4. החלף את נתוני ההדגמה בנתוני העסק כשנרצה להפוך את התרחיש לממשי.

## פתיחת ממשק הניהול

1. בחר **פריסה > פריסה חדשה**.
2. סוג פריסה: **אפליקציית אינטרנט**.
3. הפעלה בשם: **אני**.
4. גישה: **רק אני** בשלב ההדגמה.
5. פרוס ופתח את כתובת ה־Web App.

## בדיקת זרימה

1. הוסף שתי הזמנות עם מוצרים שונים ותאריך מסירה קרוב.
2. במסך **תוכנית ייצור**, בחר טווח שכולל את תאריכי המסירה ולחץ על **בנה תוכנית**.
3. ודא שבמסך **רכש** מופיעים חומרי גלם מאוחדים ולא רשימת הזמנות.
4. במסך **תוכנית ייצור**, פתח את האצוות ובדוק שהכמויות במתכון גדלו בהתאם.
5. במסך **אריזה ומסירה**, עדכן את סטטוס כל הזמנה.

## מגבלה מכוונת בגרסה הראשונה

רשימת הקניות מחושבת לפי צורך ברוטו. המערכת עדיין אינה מפחיתה מלאי קיים או מעגלת לאריזות ספק. זהו שלב הרחבה עתידי, אחרי שנאמת שהזרימה הבסיסית נוחה לאופה.
