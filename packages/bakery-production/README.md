# BakeFlow — מערכת תכנון ייצור שבועית למאפיית בוטיק

## מטרת התרחיש

BakeFlow היא מערכת עבודה פנימית לבעל מאפייה או קונדיטוריה קטנה.  
היא אינה חנות מקוונת ואינה מיועדת ללקוח הקצה. בעל העסק מזין בעצמו לאורך השבוע הזמנות שקיבל, והמערכת הופכת אותן לתוכנית פעולה מעשית: רכש, ייצור, אריזה ומסירה.

## הערך העסקי

במקום לעבור ידנית על הודעות, לחשב כמויות ולהחזיק בראש למי שייך כל פריט:

1. ההזמנות נרשמות במקום אחד.
2. המערכת מאגדת את כל הביקוש לתוכנית ייצור שבועית.
3. רשימת הקניות מחושבת לפי חומרי הגלם של כלל המוצרים.
4. כל מתכון מוצג בכמות המוגדלת הנדרשת בפועל.
5. בשלב האריזה, כל פריט משויך להזמנה וללקוח הנכונים.
6. בעל העסק רואה מה ממתין, מה בייצור, מה מוכן ומה נמסר.

## גבולות ה-MVP

### כלול

- קטלוג מוצרים, עם מתכון, שלבי עבודה, זמן הכנה ועלות.
- מאגר חומרי גלם: יחידת מידה, עלות ליחידה וספק אופציונלי.
- הזנת הזמנה ידנית: לקוח, תאריך מסירה, פריטים, כמות והערות.
- תוכנית ייצור לפי תקופת עבודה נבחרת.
- רשימת רכש מצטברת לפי חומר גלם, כמות ועלות משוערת.
- מתכון מוגדל לפי כמות הייצור.
- רשימת אריזה לפי הזמנה ולקוח.
- סטטוס הזמנה: ממתינה, מתוכננת, בייצור, מוכנה לאריזה, מוכנה למסירה, נמסרה.
- מסך ניהול mobile-first עבור בעל העסק.

### מחוץ ל-MVP

- חנות או טופס הזמנה ציבורי ללקוח.
- סליקה.
- ניהול מלאי מלא; בשלב הראשון הרשימה מציגה צורך ברוטו.
- ניהול ספקים ורכש בפועל.
- משלוחים ומעקב שליחים.
- ניהול עובדים והרשאות מרובות.

## שרשרת העבודה

```text
הזמנות ידניות
  → סגירת חלון העבודה
  → תוכנית ייצור לפי מוצר וכמות
  → רשימת רכש מאוחדת
  → מתכון ושלבי עבודה לכל אצווה
  → אריזה לפי לקוח
  → מסירה וסגירת הזמנה
```

| שיוך אריזה | חיבור אצווה להזמנה | מזהה הזמנה, מזהה מוצר, כמות, מצב אריזה |

## חישובי הליבה

### דרישת חומרים

לכל חומר גלם:

`כמות נדרשת = Σ(כמות מוצר מוזמנת × כמות חומר במתכון ליחידה)`

`עלות משוערת = כמות נדרשת × עלות חומר ליחידה`

### תוכנית ייצור

לכל מוצר:

`כמות לייצור = Σ(כמות כל שורות ההזמנה הפעילות בתקופת העבודה)`

### אריזה

לאחר סימון אצווה כזמינה, המערכת מציגה את ההזמנות הפתוחות לאותו מוצר ומאפשרת לסמן את הכמות שנארזה לכל לקוח.

## מסכי המערכת

1. **דשבורד שבועי** — הזמנות פתוחות, תאריכי מסירה קרובים, מצב התוכנית והפעולה הבאה.
2. **הזמנה חדשה** — הזנה מהירה של הזמנה שקיבל בעל העסק.
3. **תוכנית ייצור** — יצירה ופתיחה של תוכנית לפי טווח תאריכים.
4. **רשימת קניות** — סיכום חומרי גלם ועלות צפויה, לא לפי הזמנות.
5. **ייצור** — אצוות פעילות, מתכונים מוגדלים ושלבי ביצוע.
6. **אריזה ומסירה** — רשימה לפי לקוח, סימון מוכנות ומסירה.
7. **קטלוג** — מוצרים, מתכונים וחומרי גלם.

כל מסך מציג את הפעולה הבאה של האופה, ולא רק נתונים.
