# Daily Reminders

Google Apps Script mini-project for fast daily reminders, recurrence management, and Google Calendar notifications.

## Planned structure

- `apps-script/` — server-side Apps Script services
- `ui/` — mobile-first web interface
- `database/` — Google Sheets data model
- `docs/` — product and technical documentation
- `tests/` — test scenarios and validation
- `deployment/` — deployment and permissions instructions
